# **App Name**: ChirpChat

## Core Features:

- Contact List Sync: Sync with the device's contact list to automatically add contacts to the app.
- One-to-One Chat: Enable users to engage in individual text-based conversations.
- Real-time Messaging: Facilitate the instant sending and receiving of messages.
- Media Sharing: Allow users to share images and videos directly within chats.
- Read Status: Indicate when a message has been read by the recipient using visual cues.
- Smart Reply Suggestions: AI tool suggests quick reply options based on the content of incoming messages. This tool looks at both conversation history and general language patterns to choose reasonable suggestions.

## Style Guidelines:

- Primary color: Deep sky blue (#3399FF) for a vibrant and engaging feel.
- Background color: Light gray (#F0F0F0), very slightly tinted with the primary color.
- Accent color: Soft green (#99FF99) to indicate online status and successful actions, and to contrast nicely with the analogous primary hue.
- Font: 'PT Sans', a humanist sans-serif font, will be used for both headings and body text.
- Use simple, outline-style icons for navigation and common actions.
- Employ a clean and intuitive layout, focusing on message bubbles and clear contact organization.
- Incorporate subtle animations for message sending, receiving, and read status updates.
